## Public work

- [csv-quality](https://github.com/vugarbbakhishov-hub/csv-quality) - a zero-dependency TypeScript library and CLI for inspecting CSV files or piped input, with completeness and duplicate checks, CI quality gates and CSV, JSON or Markdown reports. [v0.4.3 release and installable package](https://github.com/vugarbbakhishov-hub/csv-quality/releases/tag/v0.4.3).
- [Local CSV Lens](https://github.com/vugarbbakhishov-hub/local-csv-lens) - a browser-only React and TypeScript tool for inspecting CSV completeness, duplicate rows, column types and quality issues, with one-click examples and a paginated data preview. [v0.6.0 release](https://github.com/vugarbbakhishov-hub/local-csv-lens/releases/tag/v0.6.0). [Live demo](https://vugarbbakhishov-hub.github.io/local-csv-lens/).
- [Log Pattern Lens](https://github.com/vugarbbakhishov-hub/log-pattern-lens) - a browser-only React and TypeScript utility for opening local log files, folding stack traces, detecting and masking possible sensitive values, grouping repeated messages across request IDs, filtering patterns by level and exporting CSV/JSON reports. [v0.4.0 release](https://github.com/vugarbbakhishov-hub/log-pattern-lens/releases/tag/v0.4.0). [Live demo](https://vugarbbakhishov-hub.github.io/log-pattern-lens/).
- [DataLabAcademy](https://github.com/vugarbbakhishov-hub/datalabacademy) - an education platform built with PHP, HTML, CSS/SCSS and JavaScript.
